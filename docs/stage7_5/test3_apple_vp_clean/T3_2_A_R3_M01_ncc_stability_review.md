## 2. 数值根因

`best_match` 对模板去均值，用 FFT 计算分子。窗口分母的能量通过前缀求和恢复。设 S 和 Q 分别为样本与样本平方的前缀和，长度为 n，则窗口中心化能量为：

~~~text
E[k] = (Q[k+n] - Q[k]) - (S[k+n] - S[k])² / n
D[k] = sqrt(max(E[k], 0) * reference_energy)
NCC[k] = FFT_dot[k] / D[k]    when D[k] > 1e-12
~~~

前面有较强信号时，小窗平方值可能在前缀累加时被舍掉，两个接近的 Q 值相减后会低估或抹掉窗内能量。直流分量显著时，去均值能量还可能在第二次相减时抵消。本实现先按未经裁剪的 |NCC| 选择时移，再将胜出分数裁剪到 [−1,1]。因此劣化的分母能制造错误第一名，输出也会掩盖越界。 [冻结 NCC 实现](../../../tools/reference_host_comparison/m20_echo.py#L53)

### 2.1 合成等值复现

24 kHz、960 样本、候选起点为样本 2。搜索包含前两个较强样本 0.5、−0.5；其后为峰值接近零的浮点样本。两组有相同分组权重的零均值正交序列按 −3:4 混合，直接相关系数为 −3/5。80 位十进制有效精度的 Decimal 对照从输入 float64 的精确值开始，在同一窗独立重算去均值能量和点积。

~~~python
import numpy as np
from m20_echo import RATE, best_match

u = np.tile([1., -1., 1., -1.], 240)
v = np.tile([1., 1., -1., -1.], 240)
weights = np.ones(960)
weights[:4] = 2.
x = .075 * np.sqrt(np.spacing(.5)) * weights * (-3. * u + 4. * v)
reference = .25 * weights * u
signal = np.r_[.5, -.5, x]
fast = best_match(signal, reference, 0., 2 / RATE)
x0, y0 = x - x.mean(), reference - reference.mean()
direct = np.dot(x0, y0) / np.sqrt(np.dot(x0, x0) * np.dot(y0, y0))
assert fast["ncc"] == -1. and fast["start_seconds"] == 2 / RATE
assert abs(direct + .6) < 1e-12
~~~

| 同一候选窗 | 冻结快算 | 直接高精度对照 |
|---|---:|---:|
| 窗内中心化平方和 | 2.220446e−16 | 1.517536e−14 |
| 归一化分母 | 1.161431e−7 | 9.601579e−7 |
| 相关分子 | −5.760947355266e−7 | −5.760947355833e−7 |
| 裁剪前 NCC | −4.960217 | −0.600000 |
| 返回 NCC | **−1.000000** | **−0.600000** |

快算窗能量仅留 2 个 ULP，约为真值的 1/68.34。FFT 分子的绝对误差约 5.67e−17。保留 FFT 分子并换成直接分母得 −0.599999999941；只换直接分子、保留快算分母仍得 −4.960217。将候选窗口单独截出后调用快算也回到 −0.600。上述对照把本合成主例的故障定位到分母，而裁剪和排序放大了其影响。上轮真实 40 毫秒异常出现相同的分数分歧，具体窗里的分子、分母误差各占多少仍 UNKNOWN。

### 2.2 FFT 与近静音边界

保持较强前缀，令候选窗幅度依次乘 2⁻⁸ 和 2⁻¹⁶。两次快算窗方差均为 0，直接分母仍高于原 1e−12 下限，直接 NCC 均为 −0.600。只替换分母后，保留 FFT 的 NCC 分别为 −0.599999986 和 −0.599994019，说明分子有有限绝对误差，分母越小，其归一化影响越大。继续缩至 2⁻²⁴ 和 2⁻³² 时，直接分母本身低于原下限，直接法保留无有效分数的行为。

另一个合成窗整体以 0.25 为中心，叠加可用 float64 表示的微小变化。快算获得 60.0 − 60.0 = 0，直接中心化平方和为 3.252607e−16，NCC 为 −0.600。只缩小搜索块或重新起算前缀，仍无法解决此类直流抵消。

## 3. 合成验证

候选方案将每个候选窗和模板先减各自首值，再减各自均值，直接计算点积及平方和。使用固定大小分块枚举原有全部时移，最后才比较绝对值、保留符号。与 Decimal 对照在本轮关键测试中的直接分数差小于 1e−12。短窗 80 毫秒模板在 300 毫秒的搜索宽度下约有 1383 万个样本乘积，适合对有限的离线候选窗执行。

| 合法数值范围内的阈值跨越 | −0.280624 | −0.200000。以原 0.25 NCC 子判据比较会得不同结果 |
| 位次受伪峰影响 | 在样本 1922 选到 −1.000 | 全窗重算在样本 0 选中 +0.986394。快算获胜窗的真实分数为 −0.600 |
