# T3.2-A · Step 4-C 与 A/B/C 综合归因

## 1. 裁定

**本次 C 轮在 −12 dB 居民数字电平下观察到明显但局部的近端男声保留改善。关联等级为 `SUPPORTED`。** B/C 同源内容配对中，C 的播放窗内男声 FIR 投影 RMS 比 B 高 **4.26–5.32 dB（400 ms）**、**4.60–4.69 dB（100 ms）**及 **4.56–4.66 dB（50 ms）**。三轮共同源内容覆盖中，C 相对 B 仍高 **2.36–3.36 dB**，且低于全零 A。短窗深度失配累计缩短约 0.5 秒，连续段缩短，C 仍有若干明确的音节局部失配。单次每臂结果无法估计跨运行统计显著性。

**居民起音回声是否改善为 `UNKNOWN`。** C 的起音窗内有约 100 ms 的可疑居民样残留，在固定偏移的两个相邻 50 ms 窗中重现，同一偏移的 A 全零对照接近零。500 ms 整窗相关及错时对照仍不足以确认回灌或量化回声差。数字播放电平变化为实测；实际声压、Apple VP 内部抑制与 AGC 机制未识别。

## 3. 同源时间对齐和测量口径

| 轮次 | PCM 零点的 Windows 素材位置 | 用于比较的软件播放窗 |
| --- | ---: | --- |
| A 全零 | 4.518250 秒 | 4.234175–7.981831 秒，软件投影 |
| B 原幅 | 5.119125 秒 | 4.234088–7.981746 秒，实际非零 Render |
| C −12 dB | 5.191625 秒 | 4.266093–8.013502 秒，实际非零 Render |

C 相对 B 和 A 的数字内容相位分别领先 **72.5 ms** 和 **673.375 ms**。C 实际非零 Render 窗相对各自 PCM 零点约晚 B **32 ms**，因此按各轮实际软件锚点划阶段，再平移至相同男声源样本。Windows WAV 为 48 kHz、60.370 秒循环。复用 8 kHz 处理率、150–3400 Hz 零相位带通、26 个 640 ms 窗和五档 ±2000 ppm 粗搜。多个有声窗得到共同素材位置。继续采用 0 ppm 模型，窗外留出 NCC 中位数 A/B/C 为 **0.895 / 0.935 / 0.921**。相位来自信号内容，无法反推物理起播时刻、真实传播时延或入射声压。

- **400 ms 原口径**沿用完整 20 ms 边界、窗外交替有声训练/留出、161 系数约 ±10 ms 的 FIR、参考 RMS ≥0.004、逐窗中心化 NCC 和原非负功率投影。400 ms 训练和相位在短窗计算前冻结。反相、静窗、错时及合成增益对照仍通过，已知 −15 dB 的合成混合回归读回 −14.936 dB。
- **100 ms / 50 ms 补充口径**用固定相位与同一 FIR，在各阶段按等长不重叠窗复测，不给短窗单独找最佳 lag。只有参考有声窗进入男声统计。`深度失配`用于描述时长，指同窗男声有符号 NCC <0.30 且投影增益较本轮窗前 400 ms 有声窗中位数低至少 20 dB。近静音导致 NCC 不可可靠估计的窗单列，并纳入有声源无可匹配残留的时长统计。数值仅作本报告的描述，正式门槛及 400 ms 既有判据均未修改。
- **同源直接波形**用同一 8 kHz 参考索引逐样本配对，要求整窗位于两轮或三轮同一个阶段且达到既有参考有声门槛。直接 NCC 只用去均值后的两段带通信号，不经过 FIR、不另搜偏移、不翻转极性；两侧 RMS 低于数值底线时剔除该窗的直接 NCC，仍保留在投影及深度失配统计中。换窗起点做敏感度测试。不同窗格来自同一批音频。

## 5. 居民起音 500 ms

以各轮实际非零 Render 起点切出 500 ms，A 用已冻结的全零投影起点。居民参考以首秒静默后的数字起点为中心，在原 ±250 ms 偏移范围内检验完整 500 ms 峰及五个 100 ms 的共同偏移。在原录音与扣除同一 400 ms 男声投影后的残差上分别计算。负控使用反向居民模板、+0.75/+1.25/+1.75/+2.25 秒错时源和 A 的全零录音。复核原始文件模板和套用各自实际 Fade 的模板，C 的 4.5 ms Fade 相对变化按幅度处理重建，未平移整条居民源。已知合成偏移 4.625 ms 正控、反向及静窗负控均通过。

## 6. 唯一优先的后续决策

**维持生产电平与声学门槛，优先做一次既有 DEBUG 综合 C 的 AGC ON/OFF 单变量对照。** 两臂固定原幅居民、双端 VP、原排程、实际设备与两声源摆位，并根据本轮对齐结果预先锁定相同 Windows 素材位置，验收相同有声 400/100/50 ms 窗的投影、NCC、最长失配及初始 500 ms 残留。时钟、路由、身份或覆盖不合格按原机制停封。若 OFF 仅在居民有声窗消除深度失配而窗前和窗后资格维持，支持该效应依赖 AGC 设置。若两臂同样失配，则降低 AGC 设置单独解释的优先级。该对照需要另行批准。现有数据不支持将 −12 dB 定为最终修复，也不能把关联归于 AEC、NLP 及 AGC 中某一个机制。 [现有 DEBUG 综合 C 配置入口](../../../apps/macos/Aftelle/ContentView.swift#L837)
