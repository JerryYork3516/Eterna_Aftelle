## 2. 复核 P0-C.2 的 35 个排除窗口

## 3. 本轮探索性短窗

依照 P0-C.1 的短窗方法，采用 700–3400 Hz 四阶 Butterworth 零相位带通和 24 kHz 的逐样本滞后网格，共 12,241 个名义候选，范围为 −160 至 +350 ms。对齐以 AUHAL 实际首个非零帧及有效采集包的 HostTime 中位锚点为准。重跑 A、B、C 的数字起音分别位于评分 WAV 的 1.028062、1.025328、1.024543 秒。20、50、100、200、500 ms 前缀均从同一素材首个非零样本开始。首 500 ms 另外固定为十个不重叠 50 ms 块，按奇偶交替拟合与留出，三臂等权选择单一共享候选。相关使用去均值归一化 `r`，拟合统计为 `r` 的均方根。错时 +1.280 秒在读取相关结果前按三臂时标支持确定，另用逐窗反转和数字非播放对照。对照采用相同候选与留出规则。所有位置使用原短窗法的时标和一 PCM16 量化步长资格。[P0-C.1 短窗方法](https://github.com/JerryYork3516/Eterna_Aftelle/blob/43cbae14f0d7658adabab9e91c47f989ca4064f8/docs/stage7_5/test3_apple_vp_clean/Stage_7_5_11_split_AUHAL_P0_C_1_onset_echo_review_2026-11-28.md)

前置数字非播放对照从评分 WAV 的 0.166 秒取基点。完整十窗的跨臂、跨负控共同候选为 **0**。重跑 A 的前置对照在素材首 300 ms 对应的六块中虽有合格时标，带限幅值低于一量化步长。C 的实际 300–350 ms 目标块也因幅值条件无候选。

### 后续居民残声与人声

在素材 0.50–3.75 秒的 65 个后续 50 ms 块中，有 8 块在同一网格内存在三臂和负控共同候选。在起音的唯一诊断读数上，65 块均有至少一臂或负控幅值失格，17 块同时涉及时标失格。因此后段仍为 `UNKNOWN`。保留同一读数，未按段重选滞后。

重跑 A、B、C 均报告轻微压低，吞字与音量波动缺少分项见证。混合录音缺独立校准近端，无法量化真人独立衰减、恢复或 ERLE。B、C 的约 2.26 秒和 10.27 秒数字间隔与重跑 A 的首次有声明确区分。现有回听和匹配支持不足以区分播放历史贡献。建议路线 C 的依据是当前证据不足，再次跑同组 A/B/C 缺少新增的独立见证。
