# T3.2-A · Step 4 外部独立声源双讲归因审核

## 1. 裁定

Run `5CA15A14-3DC1-4315-9C73-638D790F9C07` 的录音在居民 Render 前和结束后均能可靠匹配 Windows 男声，并能沿同一数字对齐在 Render 期间跟踪到男声成分减弱、随后恢复。三段分别计算，居民 Render 期间的可匹配男声分量较前段低 **15.85 dB**。在固定带宽和线性模板投影的口径内，该分量解释约 **72.4%** 的混合功率降幅。两种留出拆分得到 **71.2%** 和 **77.0%**。这支持本次能量下降主要伴随可识别男声分量减弱，证据等级为 **SUPPORTED**。

Native 混合 RMS 实测下降 **14.63 dB**，来源于 Apple VP 后、PCM Converter 前的同窗统计。Native 短窗只有混合能量。Windows 实际入射到 TinyUSB 的声压、持续发声与 Mac 扬声器物理重叠时长均为 `UNKNOWN`。现有数据无法把上述数字解释为麦克风入射男声的实际增益变化，也无法区分 Apple VP、AGC 或外部声学变化。居民回声的稳定模板证据不足，归属保留 `UNKNOWN`。

## 3. 数字对齐和对照

- 三份 WAV 在内存中转换到 8 kHz，采用零相位 150–3400 Hz 带通。NCC 保留符号，按绝对值比较峰，FFT 提名的峰用逐窗口中心化点积复核。两侧低于规定观察底线的窗不作可靠匹配。所有分析参数均为本报告专用，冻结检测器、正式阈值及评分口径不变。
- 以 PCM 第一包为零点。26 个 640 ms 搜索窗以 540 ms 间隔覆盖录音。每窗对 60.370 秒完整循环逐样本搜索，含接缝，并以 −2000、−1000、0、+1000、+2000 ppm 搜索数字速率偏差。多个前后段窗收敛到同一素材位置族，锁定录音零点附近的素材时间约 **4.188 秒**。该映射覆盖素材约 4.188–19.068 秒，段内无需跨循环接缝。宽搜索的单个峰也可能很高，反向对照即出现此现象，因此用跨独立窗口的共同相位检验。
- 固定数字相位后，在居民 Render 外用交替的 400 ms 窗拟合 161 系数、约 ±10 ms 的正则化 FIR，预测房间和录音链在该频带内对 Windows 参考的线性形状。预期源 RMS 至少 0.004（约 −48 dBFS）才计为参考有声窗。主拟合由 12 个外段窗训练，其余 12 个合格外段窗验证。0 ppm 的留出 NCC 中位数为 **0.9181**，−10 ppm 为 0.9156，+10 ppm 为 0.8750。±50 ppm 的留出相关已降到 0.6515、0.6642。采用 0 ppm 作为简约对齐模型，搜索结果用于约束数字错位，物理传播时延和设备晶振偏差仍未测得。
- 错时对照分别移相 ±1、±2、+5 秒，三段相关绝对值中位数均 ≤0.029。个别控制窗绝对值可达 0.333。分析不以孤立峰认定声源。合成对照覆盖 10 秒循环接缝、510 ppm 偏差、两路混合、已知 −15 dB 衰减、静窗、反相和错时。混合回归恢复 −14.936 dB 和已知第二路增益 0.0750，程序均通过断言。合成结果仅验证分析手段。
- 居民非零 Player Render 在 PCM 内容坐标上为 **4.234090–7.981746 秒**。完整落在窗口内侧的 20 ms Native/PCM 窗用于混合能量统计，两条跨界短窗排除。模板统计再用各段完整的 400 ms 窗。软件内容时标用于这些比较，实体扬声器与近端发声的物理时标没有独立测量。

## 5. 居民模板与证据等级

以固定居民 WAV 的 1 秒静默之后为起点，将 6 个连续 500 ms 窗与软件 Render 坐标对应，限定在同一 ±250 ms 数字偏移网格。原录音和去除可匹配男声投影后的残差均进行正向及反向测试。原录音的跨窗共同偏移处，正向与反向的峰值中位绝对 NCC 为 **0.0582 / 0.0772**。残差为 **0.0587 / 0.0587**。各正向峰的偏移未收敛。短窗边缘复核里，4.24–4.44 秒局部峰约 −0.429，下一窗局部峰约 −0.354，两个各自最优偏移相差约 223 ms，欠缺共同时间映射。尾部复查没有发现一致匹配，部分低能量窗无可判定峰。居民回声微弱、短促或经非线性变形时可能避开此方法，本轮无法可靠估计其独立能量。

## 6. 一项后续鉴别实验

只改变 **Mac 端播放内容**，比较同格式、同帧数的全零文件和固定居民文件，各一轮。沿用原综合 C、同一冻结构建及设备摆位，TinyUSB 60%、Mac mini 内置扬声器 55%、VP ON、AGC ON。保持 Windows 播放源、起播相位、音量、固定位置及开始流程一致，取得独立现场有效播放及重叠见证。全零轮用同一调度时标投影居民轮的评估窗。预先冻结对齐与比较口径并保持每轮独立、同一既有时长上限。

若只有居民臂复现可匹配男声的大幅下降，支持下降与居民播放条件有关。若两臂类似，孤立的居民内容触发解释减弱。任一臂无法核验音频身份、物理播放、近端对齐、时钟或有效覆盖，停止并记录不可判定。该设计仍无法直接识别 Apple VP 内部模块，需要另行授权。
