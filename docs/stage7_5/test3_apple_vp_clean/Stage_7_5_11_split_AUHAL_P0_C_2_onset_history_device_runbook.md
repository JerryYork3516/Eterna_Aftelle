# Stage 7.5.11 · P0-C.2 三臂起音实验操作说明

状态为待实机核验。独立授权须覆盖麦克风、扬声器以及目标段录音的本机留存。正式 Test3 保持 BLOCKED。

## 入口与单臂操作

使用启用了 `DEBUG`、`NATIVE_VOICE_SAME_FRAME_DIAGNOSTICS`、`NATIVE_VOICE_DIRECT_VPIO`、`APPLE_NATIVE_VOICE_P4_DEVICE_AUTHORIZED` 和 `APPLE_NATIVE_VOICE_ACOUSTIC_EVIDENCE_AUTHORIZED` 的专用候选。授权后用唯一参数 `--apple-native-voice-split-auhal-onset-history` 打开实验窗口。启动本身只打开待机窗口。普通同帧和 Split AUHAL 单段入口有独立参数。

1. 用文件选择器选择固定原幅居民 WAV。执行器核对 SHA-256 `774e450ce1ff92402051f89ae4fcd537d74367deff9c2f92670ba0f6637d47ea` 及其 114,032 个 24 kHz 单声道 PCM16 样本。两槽静音复用相同长度的零值 PCM。目标居民素材和增益保持原样。
2. 同一实验窗口内选择一臂，勾选目标段 15 秒录音留存，按正常的开始确认和系统权限流程进入此次运行。窗口 UUID 标识配对组，每次开始生成新运行 UUID、双工图和采集身份。按授权前锁定的顺序做 A、B、C，跨配对组平衡顺序。新配对组用新窗口 UUID。每次单独开始及停止，保留失败记录。
3. 等待提示期间保持安静。若听到预播放，仍等到窗口提示「现在讲话」。从提示起按原声量朗读固定台词，目标居民实际外放时继续讲话。各臂可统一使用「我按平常的速度读这一段话。窗边放着一本书，桌上有一杯水。我会继续用相同的音量说下去。」读完可原速重读，看到停讲提示即停，保持安静直到结束。
4. 「停止会话」会取消当前臂。正在播放时，以后继 token 请求原清空契约，最多观察 50 ms 的真正消费者回执。即使回执缺失也关闭双单元，并记录为未观察到。应用内结束后可显式保存本机证据。完成且有连续评分 PCM 才产出 WAV，失败和取消保留技术 JSON。任何中断都先记原因，禁止自动重做。

## 统一计划

所有时刻以双工图启动成功的单调 HostTime 为原点。每臂内保持一组 VPIO/AUHAL、采集身份、设备路由及处理参数。每槽使用独立的后继播放身份，依赖实际数字 EOS 转移。

## 有效性与评分

- 三臂核对设备身份、实际路由、格式、音量、VP／AGC／Mic Mode 状态以及目标图龄期。预注册允许的时差和重复性边界，数字预算之外保留实际偏差。留存每槽的计划、首次接受的入队请求、AUHAL 首次提交、首非零及数字 EOS，核对录音采集身份、时间资格和计数。未达到工程合同、诊断丢帧、路由／音量变化、缺见证或超出配对容差的臂单独标记无效。
- 实际扬声器起停用独立物理见证记录。真人反馈单列是否看到提示、实际听到外放、持续说话并遵守停讲。只有独立对齐的记录才给出物理时标。提示、入队、数字 EOS 和清空回执都只描述数字事件。
- 对可比臂使用同一锁定算法。以实际首非零及有效 HostTime 对齐目标段，按同一带宽 700–3400 Hz 和预注册的滞后范围 −160 至 +350 ms 做去均值归一化互相关。先在盲化的三臂后段固定窗口（素材 0.5–3.5 秒，50 ms 窗）按臂等权拟合**一个共同滞后**，用交替留出和等搜索预算负控判断是否足以锁定。间隔、阈值和物理同步质量须在看结果前登记。后段信息不足时将定量对照记为不确定。P0-C.1 的 114.417 ms 不用于预设，也不在目标窗为每臂分别挑峰。
- 锁定滞后后，主评分观察素材首 0–250 ms，用相同的 20／50／100／200 ms 窗和不重叠的 50 ms 分块报告 r 与匹配投影。保留后段和回弹观察。负控使用同长度错时（至少 650 ms）、模板反转和经证实的非播放窗，排除与时间资格失效或独立物理见证冲突的窗口。交替窗是同一录音内的一致性检查，独立试次以单臂运行身份区分。
- 同步记录居民首字完整性、真人吞字／受压／恢复和自然响应。无校准的独立近端参考时保留盲听比较，真人独立衰减、瞬时抑制及恢复的客观量保持 UNKNOWN。暖臂改善首先只支持有声历史效应。Apple AEC 收敛机制、声源资格与正式插话门禁分别处理。

本地保存沿用原私有目录，目标 WAV 与技术 JSON 默认不传输。现场新增录音保存和后续试次须另行授权。
