# Stage 7.5.11 · Native Transport 真人双讲 WAV 复听 · 2026-11-28

## 验收结论

**本次双讲声学验收未通过。** 操作者回听完整的 VP 后麦克风 WAV，确认居民声音仍可辨认，自己的声音在居民播放期间也听得出受压。居民声残留有固定原幅素材的波形匹配佐证。近端受压是本次回听结果，独立衰减量和导致受压的具体处理环节仍未知。

本报告记录同日的 WAV 导出复测。此前仅保存技术统计的[首轮同帧试次](Stage_7_5_11_native_transport_human_double_talk_same_frame_2026-11-28.md)仍保留其 `NOT_RUN` 回听状态，两次的观测结果分开记录。

## 试次与载荷

- 使用源码 `fe88022bb0f2122bd294d6b59d7eba5218fb1e35` 的签名 Debug 专用入口 `--apple-native-voice-same-frame-diagnostics`。实际 Debug dylib SHA-256 为 `03068e73c09573e1607b4833ef976e52df99d06a16eb1310cacfe486be8382ff`，与本机技术 JSON 中的载荷摘要一致。[固定源码提交](https://github.com/JerryYork3516/Eterna_Aftelle/commit/fe88022bb0f2122bd294d6b59d7eba5218fb1e35) · [同帧诊断合同](Stage_7_5_11_DEBUG_same_frame_diagnostics.md)
- 在同一会话内进行一次 15 秒采集和一次固定居民 WAV 原幅播放。操作安排为开始后讲话、第 3 秒送入素材、第 11 秒提示停讲。分析使用实际数字 Source 时标。固定素材为 24 kHz 单声道 PCM16LE、114,032 个样本，前 24,000 个样本为原素材静音，SHA-256 为 `774e450ce1ff92402051f89ae4fcd537d74367deff9c2f92670ba0f6637d47ea`。本地 WAV 路径不调用 Provider 或 Runtime。
- 会话起止的默认输入为 TinyUSB，默认输出为 Mac mini 内置扬声器。主通道音量读回分别为 60.49% 和 59.86%，均未静音。active 和 preferred Mic Mode 均为 Standard，VP 输入、输出和 AGC 均为 ON，bypass 和 inputMuted 均为 OFF。两端 AudioUnit 的 Global 当前设备 ID 相同，实际物理麦克风的独占绑定仍未知。
- Sink 和 Output 协商客户端格式为 16 kHz、3ch、非交错 Float32，Source 为 16 kHz 单声道 Float32。导出的 VP 后 WAV 为 24 kHz 单声道 PCM16LE、360,000 个样本。完整 15.000 秒 WAV 与原幅居民素材均在本机与 JSON 摘要核对一致。公开提交仅保存脱敏结果。

## 时间轴与完整性

- 使用 `VALID` 包的 HostTime 减去对应 WAV 内容时间，取中位锚点。锚点最大与最小值相差 63.834 µs。用各 Source 回调的 HostTime 加块内非零范围，得到相对 WAV 起点 **4.106139–7.853903 秒**的数字非零区间，含 118 个回调、59,964 个非零帧。数字 EOS 出现在起点为 7.842778 秒的末次回调。物理外放起止和 Apple 内部参考时序未测。
- WAV 来自同一采集身份、同一内容段的 750 个连续 20 ms 包，样本序号每包前进 480。时钟资格为 741 个 `VALID`、7 个 `UNKNOWN`、2 个 `INVALID`。无资格的包位于开头或 14.70 秒后，分析的数字播放区间和两侧讲话窗口均避开这些包。
- 已接受 240,640 个原生帧，其中 240,128 帧进入同帧观测。停止时还有末块 512 帧（32 ms）留在采集环，故诊断 `complete=false`。另有 192 个 24 kHz 样本待释放或组包。录音导出完整与诊断覆盖范围分别记录。未见环溢出、丢弃、Worker 内容断点、Source 欠载或诊断队列丢失。

## 混合电平

RMS 以 PCM16 样本除以 32768 后计算。短时电平用不重叠的 50 ms 窗，P90 仅计整窗。采集包含开始时的短静音和讲话自然停顿。

| WAV 内容时间（秒） | 混合 RMS（dBFS） | 50 ms P90（dBFS） | PCM16 满幅样本 |
| --- | ---: | ---: | ---: |
| 播放前参考 0.250–4.006 | −17.69 | −12.24 | 27 |
| Source 非零窗 4.106–7.854 | −20.62 | −16.94 | 0 |
| 播放后 8.354–10.750，留出 0.5 秒保护窗 | −25.72 | −20.48 | 0 |
| 预计停讲后 11.250–15.000 | −41.17 | −39.85 | 0 |

数字播放窗的混合 RMS 比前窗低 **2.93 dB**，前后窗口的讲话、停顿和残余分量无法单独匹配。播放后的较低电平也无法单独表征处理器的恢复时间。

## 居民残留检验与回听定位

- 对录音和固定原幅 WAV 做 700–3400 Hz 四阶 Butterworth 零相位带通。从居民 WAV 的第一个非零样本起取七个整 0.5 秒窗，按 Source 数字起音定位录音端的名义起点。在 −160 至 +350 ms 延迟范围逐样本计算去均值归一化互相关。用交替窗口的绝对相关中位数选取延迟，再在另一半固定延迟验证，最后交换两组。用反向模板、播放前错位窗和播放后错位窗重复同一训练与留出过程作为对照。
- 两组训练选出的匹配滞后为 **160.04 ms** 与 **160.88 ms**。留出窗的绝对相关为 **0.195–0.713**，两组中位数分别为 0.215 和 0.382。同法对照的留出绝对相关中位数最高为 0.041。最强匹配在导出 WAV **7.267–7.767 秒**，可作为人工回听定位。带宽改变会移动相关峰。滞后涵盖数字输出到 VP 后录音的链路及估计误差。
- 操作者报告可听到居民残声，也可听出自己的声音被压低。一次混合录音无法给出独立近端衰减量、ERLE、吞字发生率或 AEC 与 AGC 的贡献。记录缺少独立近端参考和未消回声原始输入。
