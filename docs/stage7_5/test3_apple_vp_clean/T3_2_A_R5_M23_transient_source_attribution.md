# T3.2-A / R5-M23：异常突发声源离线归属

日期：2026-10-29。范围：LOCAL_OFFLINE_FORENSIC_ANALYSIS；仅本轮指定的四个事件。本文“事件A–D”是时间定位编号，不代表已确认的声源类别。

## 1. 结论

- **CONFIRMED**：四个事件均为多采样的短时振荡，能量支撑范围、频带及波形明显不同；不能把历史“60ms能量集中窗”当作声音实际持续60ms。事件A的主要能量甚至超出了原指定的20ms定位窗。
- **DIFFERENT_PATTERN_SUPPORTED**：四事件的峰对齐、有限时移绝对NCC最大仅0.226；不支持同一固定波形仅经过幅度缩放/极性翻转后重复出现。**这不证明它们来自不同物理声源**，共同来源经过不同处理仍不能排除。
- **CONFIRMED**：R2事件A发生在本次唯一居民播放请求前1.802秒、Engine.start返回后11.206秒。在现有通过技术门禁的时间映射下，它不能归因于本次稍后播放的居民音频，也不贴近已记录的Engine启动或Player启动事件。
- 事件D是四者中最值得保留的**居民起音相关候选**：局部波形绝对NCC 0.609、谱相似性0.920，但反向对照仍达0.511；只有短片段相似，**SOURCE_ASSOCIATION=UNVERIFIED**。A/B/C也未取得可靠居民归属。
- 四事件所在原20ms统计窗中，Native/PCM聚合RMS差均小于0.001dB。突发已存在于**Apple VP后Native或更早环节**；现有证据不能继续区分VP/AGC处理瞬态与外部输入。未发现可确认的生产代码根因，不提出参数或生产代码修复。
