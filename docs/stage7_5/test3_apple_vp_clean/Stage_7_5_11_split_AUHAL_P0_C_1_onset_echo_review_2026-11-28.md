**本轮录音支持存在短暂居民起音残留（SUPPORTED）。** 用户回听可辨起音「这」，并确认真人讲话听感稳定。同一录音中相互错开的 50 ms 窗提供约 114 ms 数字匹配滞后的一致性证据。较强匹配集中于居民素材首 250 ms，映射到录音约 **4.192–4.442 s**。之后仍有零散相关线索。现有证据无法确定物理起音时刻、连续泄漏的精确长度或该字的逐样本边界。

## 短窗与负控

以固定素材首个非零样本为参考零点。NumPy 2.0.2、SciPy 1.13.1，对两份 WAV 作 700–3400 Hz 四阶 Butterworth 零相位带通。20、50、100、200、500 ms 均从该零点开始，逐样本扫数字起音后 **−160 至 +350 ms** 的候选滞后，取最大绝对去均值归一化互相关并保留符号。错时负控在播放区另选相隔至少 650 ms 的对齐点。反转负控逐窗翻转模板。非播放负控在起音前和结束后留有保护间隔。三类负控各做同样滞后搜索。剔除与失格包相交的搜索窗，中心波动小于一个 PCM16 量化步长时排除该位置。数值描述单次录音，不设统计通过阈值。

将首 500 ms 分成十个不重叠的 50 ms 窗，按各窗 r 的均方根选择**一个共同滞后**。最佳为 +114.417 ms，均方根 **0.272**，相同搜索的错时、反转、非播放负控峰分别 **0.160、0.184、0.187**。交替窗拟合与留出交换后，滞后为 114.417 / 114.250 ms，留出均方根 0.278 / 0.206。源窗不重叠，候选搜索的采集窗口可重叠。交替留出与直接点积仅为同一次录音内的一致性检查。300–3400 Hz 的交替窗最佳滞后约 120–121 ms，提示相关峰受带宽影响。114 ms 是本试次的数字内容匹配偏移，无法拆出 Apple 参考建立时刻。后续各臂须按预先统一的估计和负控流程选滞后，114.417 ms 仅作本轮探索记录。

## 最小动作与验收

**唯一下一项是配对验证有声历史间隔。** 每臂使用相同 Split AUHAL/VPIO 格式和设备，按相同图龄期进入同一目标 WAV 的真人双讲。每臂从启动到评分结束保持同一双工图和采集身份。将目标前的两个等长播放槽分别设在较短和较长间隔处。三臂为两槽全零（首遍有声）、近槽有声（同图后续）、远槽有声（长静音后重播），占用相同排程和 token 位置。实际有声与物理停止另作见证。间隔和容差先按物理尾音及重复性校准，平衡次序，短长臂均以首遍臂作配对。该设计同时区分首次、每轮和长静音回弹。相同图龄期的比较将启动等待与有声历史分开。

主指标为目标起音后 0–250 ms 的固定滞后局部匹配及盲听可辨残声，兼顾后段回弹。固定真人台词和物理重叠，独立近端参考可用时验证首字、吞字、响度、恢复与连续性不劣，且居民首字完整、响应延迟不增加。首帧、路由、音量、时标或见证不合格的配对记无效。缺校准近端参考时只登记相对听感，无法给出保真不退化验收。现有窗口一次只播放一段，受控多段排程属于后续就绪条件，另行审查和授权。 [现有配对准入审计](Stage_7_5_11_remote_preexcitation_pair_readiness_audit_2026-11-27.md)
