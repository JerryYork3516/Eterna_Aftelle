## 1. 裁定

全零 Run `558699DC-E5B2-4F9C-846A-EA491A936968` 在软件对照窗内仍有男声电平下降，**未复现历史有声轮的深度衰减与持续失配**。相对窗前，A 轮男声 FIR 投影 RMS 下降 **5.26 dB**，有声窗 NCC 中位数由 **0.881** 升至 **0.916**。历史居民有声 Run `5CA15A14-3DC1-4315-9C73-638D790F9C07` 在对应时段下降 **15.85 dB**，NCC 由 **0.898** 降至 **0.322**，之后回升至 **0.917**。两轮三段的统计均使用原口径。

## 3. 复用口径与对照控制

- 复用既有 8 kHz、150–3400 Hz 零相位带通及 60.370 秒循环搜索。26 个 640 ms 搜索窗、五档 ±2000 ppm 粗搜和逐窗中心化 NCC 与既有方法相同。多个前、中、后窗都匹配同一素材位置族。锚点使用 **4.51825 秒**，历史轮为 **4.18825 秒**，相差约 **330 ms**。两轮用同一文件，落在软件分段里的实际内容并非逐样本相同。这个差值属于数字对齐。
- 复用交替 400 ms OFF-window 训练及留出、161 系数约 ±10 ms 正则化 FIR、参考有声 RMS 门槛 0.004 和非负功率投影。其中 13 个外段合格窗训练，12 个外段参考有声窗留出。固定相位下 0 ppm 的留出 NCC 中位数为 **0.8947**，−10/+10 ppm 为 **0.8870/0.8621**，−50/+50 ppm 为 **0.7418/0.7785**。本次主结果用同样的 0 ppm 对齐模型，未从搜索估计物理时延或设备晶振偏差。
- 使用原错时 ±1、±2、+5 秒和全循环反向负控。全零轮错时各段 NCC 绝对值中位数最大为 **0.086**，单窗峰可达 **0.604**。反向搜索在个别低能量窗也会产生高峰，实测对齐依赖跨窗共同相位和稳定的留出匹配。原合成测试再次通过循环接缝、510 ppm、混合、静窗、反相、错时条件，恢复已知 −15 dB 为 −14.936 dB。
- A 轮对照窗固定为 **4.234175–7.981831 秒**，锚点为原软件播放事件。按同样的 20 ms 内容格排除跨界短窗，使用前、中、后段分别完整包含的 400 ms 窗。固定阈值、帧规格、模拟量和比较口径未调整。

**源内容与增益时间线。** 参考 RMS 的前中变化两轮相近，330 ms 起点偏移足以移动自然静窗。两轮在 5.84–6.24 秒均为明确参考有声且源 RMS 接近（−29.21 / −29.57 dBFS），A 轮 NCC 为 **0.921**、相对 FIR 增益 **+2.36 dB**，历史轮为 **0.045**、**−75.98 dB**。后者接近匹配失效，增益读数仅用于记录估计值。6.24–6.64 秒仍见相同方向，A 轮 NCC **0.903**，历史轮 **0.259**。因此参考源电平或近邻静窗不能单独解释历史深度失配。

复用 400 ms 有声窗观察启动基线，A 轮 0–2.4 秒和 2.4–4.0 秒中位相对增益为 **+7.53 / +9.03 dB**，历史轮为 **+9.59 / +2.28 dB**。历史轮在居民窗口之前已出现增益变化。A 轮高匹配状态下的早期高增益、窗中回落及窗后进一步回落，与历史轮窗中明显失配、窗末恢复的形态不同。两轮分别拟合 FIR，按各自基线比较增益随时间的变化，避免把两轮增益绝对值当作校准声压或据此判定 AGC 行为。
