# Test 3 / 01–02：转换时间戳回归

运行 `bash tools/speech_aec_host_tests/check-timeline.sh`。不访问音频设备、网络或凭据。
每次编译当前转换器及 capture/render 生产处理方法，输出保留在
`.build/test3-converter-timeline/run.*/`。失败返回1，所有用例仍执行；不把预期失败包装成PASS。

测试仅在临时编译副本中将三个转换器属性和两个处理方法的private可见性移除，
便于输入内存buffer；方法体不替换、不复制另一套处理逻辑。仓库生产文件不修改，
运行前后核对SHA。不创建AVAudioEngine，不调用startCapture/prepareOutput。

12个用例：48k/44.1k × capture/render × 单回调、三回调、重置后三回调。
每次原生输入固定100ms，时间从已知输入源位置定义。48k输出须逐值等于源前缀；
44.1k输出须逐值等于同一源一次性转换的前缀。输出首样本时间必须为该段源起点
加已返回48k样本的位置；每个完整480样本帧按源时间前进10ms，允许1ns舍入误差。

重置正控：capture调用实际generation丢弃方法；render模拟格式重建，使用新转换器
并清空Host帧状态。此测试不宣称覆盖真实设备热切换或硬件时钟漂移。

01建立的预期独立于旧日志：第二回调返回首样本位置4096时，其相对源时间为
85.333333ms，不能沿用输入回调的100ms。源音频前缀正确而调用/拆帧时间错误时，
测试必须保持RED；Step 02应修生产代码，不改这个预期。

本入口验证48k转换及Host拆帧；不证明24k最终包归属、真实声场或完整问题可懂度。
它作为联合验收独立入口保留，当前不把新增RED用例隐藏进旧1185检查的PASS计数。

02保留上述12例的判断，另加12例转换器边界测试：48k/44.1k各覆盖起始时间缺失、
中间时间缺失、向前跳时、向后跳时、100ns量化抖动、未知时间输入后重置。
跨越未知或不连续输入的转换输出不得伪造连续时间；后续已知连续输入必须恢复时间。
各例均检查完整返回PCM前缀，使用足够容纳四次输入的一次性转换参考。
这些边界例只验证转换器输出，未覆盖设备时钟长期漂移、Host跨不连续输入拼接帧、
或真实设备切换。Host关联/门控策略本轮未改，不能把时间回归PASS当成Test 3 PASS。
